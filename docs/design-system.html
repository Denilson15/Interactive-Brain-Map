Interactive Brain Map

Design system

The tokens and components the app is built from. This page uses the same stylesheets as the app, so it always shows what visitors see. Switch your device between light and dark mode to check both themes.

Principles

  • A calm reference work. The interface stays quiet so the 3D model and the region colors stand out.
  • Color carries meaning. Region colors identify parts; interface chrome stays neutral so it never competes.
  • Never color alone. Condition involvement also differs in shape: filled for primary, a ring for also involved.
  • Tokens only. Components use the variables in src/styles/tokens.css; nothing hard-codes a color, size or space.

Typography

Two families with separate jobs: Bricolage Grotesque for the interface and headings, Source Serif 4 for reading. One scale from the classical sizes of print; nothing smaller than 13px.

A 4px grid. Corners get rounder as elements get larger: 6px for small controls, 10px for buttons and cards, 16px for panels.

Components

Button

Actions. The quiet variant is for links inside panels; the stage variant sits over the 3D model.

Chip and swatch

Compact toggles and links. A swatch shows a region's color, or condition involvement by shape.

Tags and breadcrumbs

Tags classify (not interactive). Breadcrumbs show where a part sits in the brain and lead back up.

Accessibility

  • Text contrast at least 4.5:1; control edges 3:1.
  • Touch targets grow to 40-44px on touch screens; the visible focus ring is never removed.
  • Motion is short and functional, and turns off with the device's reduced-motion setting.
